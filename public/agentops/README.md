# AgentOps public import/fix-plan cache

This folder is the Vite static bridge used by AgentOps owner/operator tools.

The JSON files in this folder are generated outputs from `qa-agent/scripts/`. They are not source of truth, not design law, and not permanent QA evidence.

Generated JSON files are intentionally not committed:

* `static-import-plan.json`
* `browser-findings-import-plan.json`
* `role-workflow-import-plan.json`
* `role-workflow-approved-import-plan.json`
* `write-draft-findings-import-plan.json`
* `write-draft-approved-import-plan.json`
* `fix-plan-summary.json`

When these files are missing, the AgentOps UI should degrade safely and show operator guidance to run the matching generator command.

## Regeneration commands

| JSON file                               | Generator command                                      |
| --------------------------------------- | ------------------------------------------------------ |
| `static-import-plan.json`               | `npm run qa:agentops-static-import-plan`               |
| `browser-findings-import-plan.json`     | `npm run qa:agentops-browser-findings-import-plan`     |
| `role-workflow-import-plan.json`        | `npm run qa:agentops-role-workflow-review`             |
| `write-draft-findings-import-plan.json` | `npm run qa:agentops-write-draft-findings-import-plan` |
| `fix-plan-summary.json`                 | `npm run qa:agentops-fix-plans`                        |

Approved subset files such as `role-workflow-approved-import-plan.json` and `write-draft-approved-import-plan.json` are generated by the approved-import helper scripts after review.

## Runtime policy

Core AgentOps pages must not depend on these JSON files for normal app boot.

These files are only for manual import-preview, import-review, and fix-plan operator workflows.

For deployed staging/Vercel environments, either run the generators as part of an approved operator workflow or accept that the import/fix-plan operator panels will show empty or missing-plan states until the cache is generated.

Do not treat generated JSON in this folder as current staging truth. Live staging state should come from Supabase and approved AgentOps workflows.
