# Issue Agent — Job

## Mission

Manage AgentOps issue lifecycle, classify issues, deduplicate findings, prepare issue summaries.

## Scan scope

Full staging website (all inventory pages + discovered subpages). No per-agent route subset.

## Skills

Only findings and improvements that match this agent's detector pack.

## Forbidden

- Do not file issues outside this role's skill pack.
- Do not speak for other agents.
- Do not fake tool execution.
