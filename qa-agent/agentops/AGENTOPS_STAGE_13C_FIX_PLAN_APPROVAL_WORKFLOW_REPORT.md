# AgentOps Stage 13C Fix Plan Approval Workflow Report

## Purpose
Owner approval workflow for generated fix plans.

## Files Modified
- `src/lib/agentops/types.ts`
- `src/lib/agentops/service.ts`
- `src/lib/agentops/index.ts`
- `src/app/system/agent-ops/page.tsx`
- `qa-agent/scripts/generate-agentops-fix-plans.mjs`

## Files Created
- `qa-agent/agentops/AGENTOPS_STAGE_13C_FIX_PLAN_APPROVAL_WORKFLOW_REPORT.md`

## UI Added
- Added a new **Fix Plan Review** panel in `/system/agent-ops`.
- Panel loads generated fix plans from `public/agentops/fix-plan-summary.json`.
- For each plan, UI shows issue code/title, severity/category, readable summary, why it matters, affected route/module/role, recommended fix strategy, validation commands, and Cursor prompt preview.
- Added decision buttons with confirmation modal + owner note:
  - Approve Plan
  - Reject
  - Request Better Plan
  - Mark Prompt Used Manually
  - Copy Prompt Only

## Service Functions Added
- `getAgentOpsGeneratedFixPlans()`
- `recordAgentOpsFixPlanDecision(input)`
- `getAgentOpsFixPlanDecisionHistory(issueCode)` (optional history helper)

## Storage Used
- **Public JSON source for UI**: `public/agentops/fix-plan-summary.json`
  - Generated by `qa:agentops-fix-plans` from Stage 13B outputs.
  - Contains non-secret plan details and prompt text for owner review.
- **Decision audit log**: `agentops_owner_feedback`
  - Records metadata with:
    - `action: "fix_plan_decision"`
    - `decision`
    - `decisionStatus`
    - `planId`
    - `issueCode`
    - `promptPath`
    - `summaryPath`
    - `ownerApproved`
    - `cursorPromptPreview`
- **Finding metadata update (safe, no status change)**: `agentops_findings.metadata`
  - `latestFixPlanDecision`
  - `latestFixPlanDecisionStatus`
  - `latestFixPlanDecisionAt`
  - `latestFixPlanPlanId`

## What Owner Can Do
- approve
- reject
